    GitHub token

    A saved token is locked on this device.

    Make the token (5 minutes)
    1. On GitHub: profile picture → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic).
    2. Note: salvage. Expiration: 90 days.
    3. Tick repo, workflow and read:org. Nothing else.
    4. Generate, copy it, paste it above, and set a passphrase so it's stored scrambled.
    5. When it expires, make a new one the same way.

    Why classic? Creating Pages sites needs the "repo" scope, and a classic token can also publish into your organization.

    Important: keep other people's code in a separate yard

    Everything published at 7itb7.github.io shares one browser "address". Code you copy from strangers and publish there could read the keys your other apps save in the browser (for example your Google key in Tourniquet). Fix, free and one-time:

    1. On GitHub: + → New organization → Free. Name it something like 7itb7-yard.
    2. Come back, re-enter the token, and choose that organization under "Copies of other people's code go to".
    3. Copies then live at 7itb7-yard.github.io, a separate address that can't see your own apps' data.
    The free stack (what costs nothing)
    • GitHub Pages: free hosting for public repos. Sites up to 1 GB, soft limit of 100 GB of traffic a month.
    • GitHub Actions: free robots for public repos. Your robot trackers run on a schedule and save their data back into the repo.
    • github.dev: a free code editor in the browser. Open any repo and press the . key, or use the Edit button in Mine.
    • raw.githubusercontent.com: any file in a public repo can be read by any web app, so a repo doubles as a free database.
    Rules that matter
    • Licenses: MIT, Apache, BSD, ISC and similar: copy, change and even sell, as long as you keep their license file. GPL/AGPL: allowed, but your version must stay open source under the same license. No license = no permission, look but don't copy.
    • Pages is not a store. GitHub's rules say Pages can't be used as free hosting to run an online business, e-commerce site or paid software service. Free tools, portfolios and lead-generation pages are fine; paid apps need other hosting.
    • Robots: GitHub turns off scheduled robots in public repos after 60 days with no activity. The robot starter commits data on every run, which keeps it active.
    • Tokens: never paste your token into a page you didn't build, and never commit it to a repo.
